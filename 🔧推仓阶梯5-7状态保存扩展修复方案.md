# 🔧 推仓阶梯5-7状态保存扩展修复方案

## 📋 问题分析

**发现的问题**：
- ✅ 推仓状态1、2可以保存
- ❌ 推仓状态3-7不能保存

**根本原因**：
`ContractConfigViewModel` 类只定义了4个推仓状态属性：
- `PushTier1Status`
- `PushTier2Status` 
- `PushTier3Status`
- `PushTier4Status`

但UI界面支持7个推仓阶梯，推仓5-7没有对应的模型属性。

## 🔧 修复方案

### 方案2：扩展状态同步方法

**文件**：`Views/ContractConfigEditDialog.xaml.cs`

修改 `SyncPushTierStatusFromUI()` 方法以支持7个阶梯：

```csharp
private void SyncPushTierStatusFromUI()
{
    try
    {
        _logger?.LogCritical($"🔧【推仓同步】开始同步推仓状态...");
        
        // 同步推仓阶梯1-7的状态
        for (int i = 0; i < Math.Min(_pushTierComboBoxes?.Count ?? 0, 7); i++)
        {
            if (_pushTierComboBoxes[i]?.SelectedItem is ComboBoxItem item)
            {
                var newStatus = item.Tag?.ToString() ?? "-";
                string oldStatus = "-";
                
                switch (i)
                {
                    case 0:
                        oldStatus = _editedConfig.PushTier1Status;
                        _editedConfig.PushTier1Status = newStatus;
                        break;
                    case 1:
                        oldStatus = _editedConfig.PushTier2Status;
                        _editedConfig.PushTier2Status = newStatus;
                        break;
                    case 2:
                        oldStatus = _editedConfig.PushTier3Status;
                        _editedConfig.PushTier3Status = newStatus;
                        break;
                    case 3:
                        oldStatus = _editedConfig.PushTier4Status;
                        _editedConfig.PushTier4Status = newStatus;
                        break;
                    case 4:
                        oldStatus = _editedConfig.PushTier5Status;
                        _editedConfig.PushTier5Status = newStatus;
                        break;
                    case 5:
                        oldStatus = _editedConfig.PushTier6Status;
                        _editedConfig.PushTier6Status = newStatus;
                        break;
                    case 6:
                        oldStatus = _editedConfig.PushTier7Status;
                        _editedConfig.PushTier7Status = newStatus;
                        break;
                }
                
                _logger?.LogCritical($"🔧【推仓同步】T{i+1}: {oldStatus} → {newStatus}");
            }
        }
        
        _logger?.LogCritical($"🔧【推仓同步】推仓状态同步完成");
    }
    catch (Exception ex)
    {
        _logger?.LogError(ex, "❌ 同步推仓状态失败");
    }
}
```
