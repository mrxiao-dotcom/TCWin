# 配置同步功能使用说明

## 📋 功能概述

配置同步功能用于在基础配置变化时，自动同步所有合约的配置结构，确保表格列显示与实际配置保持一致。

## 🔧 集成步骤

### 1. 在主窗口中初始化配置同步管理器

```csharp
public partial class AutoMonitorWindow : Window
{
    private AutoMonitorDataModel _dataModel;
    private UIComponentManager _uiComponentManager;
    private ConfigurationSyncManager _configurationSyncManager;
    private ILogger _logger;
    
    public AutoMonitorWindow()
    {
        InitializeComponent();
        
        // 初始化数据模型
        _dataModel = new AutoMonitorDataModel();
        
        // 初始化UI组件管理器
        _uiComponentManager = new UIComponentManager(_dataModel, new UIStateModel(), _logger);
        
        // 🎯 初始化配置同步管理器
        _configurationSyncManager = new ConfigurationSyncManager(_dataModel, _uiComponentManager, _logger);
        
        // 🎯 设置配置对话框的同步管理器引用
        AutoMonitorConfigDialog.ConfigurationSyncManager = _configurationSyncManager;
        
        // 初始化UI组件
        _uiComponentManager.InitializeComponents(this);
        
        // 创建主布局
        this.Content = _uiComponentManager.CreateMainLayout();
    }
}
```

### 3. 手动触发配置同步

```csharp
/// <summary>
/// 手动同步配置按钮点击事件
/// </summary>
private void SyncConfigurationButton_Click(object sender, RoutedEventArgs e)
{
    try
    {
        // 检查是否可以同步
        if (!_configurationSyncManager.CanSyncConfiguration())
        {
            MessageBox.Show("❌ 无法同步配置：请先停止自动盯盘监控", "配置同步", 
                MessageBoxButton.OK, MessageBoxImage.Warning);
            return;
        }
        
        // 弹出配置同步选择对话框
        var syncDialog = new ConfigurationSyncDialog(_configurationSyncManager);
        if (syncDialog.ShowDialog() == true)
        {
            var selectedTiers = syncDialog.GetSelectedTiers();
            
            // 执行批量同步
            _uiComponentManager.BatchSyncAllContractConfigs(
                selectedTiers.AddPositionTiers, 
                selectedTiers.ProfitProtectionTiers);
        }
    }
    catch (Exception ex)
    {
        _logger.LogError(ex, "手动同步配置时发生异常");
        MessageBox.Show($"❌ 配置同步失败：{ex.Message}", "错误", 
            MessageBoxButton.OK, MessageBoxImage.Error);
    }
}
```

### 4. 添加新合约时的配置处理

```csharp
/// <summary>
/// 添加新合约
/// </summary>
private void AddNewContract(string symbol, string positionSide)
{
    try
    {
        var newContract = new ContractMonitorModel
        {
            Symbol = symbol,
            PositionSide = positionSide,
            IsEnabled = true,
            TriggerConditions = new ObservableCollection<TriggerConditionModel>()
        };
        
        // 添加到数据模型
        _dataModel.ContractMonitors.Add(newContract);
        
        // 🎯 使用UI组件管理器处理新合约配置
        _uiComponentManager.HandleNewContractAdded(newContract);
        
        _logger.LogInformation($"新合约 {symbol} {positionSide} 添加成功");
    }
    catch (Exception ex)
    {
        _logger.LogError(ex, $"添加新合约 {symbol} {positionSide} 时发生异常");
        MessageBox.Show($"❌ 添加合约失败：{ex.Message}", "错误", 
            MessageBoxButton.OK, MessageBoxImage.Error);
    }
}
```

## 🎯 使用场景

### 场景1：通过配置对话框修改阶梯数量

1. 用户打开配置对话框
2. 修改推仓阶梯或止盈阶梯数量
3. 点击确认时，自动检测配置变化
4. 提示用户是否同步现有合约配置
5. 用户确认后，自动同步所有合约并刷新表格列

### 场景2：手动批量同步配置

1. 用户点击"同步配置"按钮
2. 弹出配置同步对话框
3. 用户选择目标阶梯数量
4. 系统批量同步所有合约配置
5. 自动刷新表格列结构

### 场景3：添加新合约时的自动配置

1. 用户添加新合约
2. 系统自动为新合约配置当前的阶梯结构
3. 表格自动刷新显示新合约

## 📝 开发说明

### 主要类说明

1. **ConfigurationSyncManager**：配置同步管理器，负责处理配置变化和同步逻辑
2. **UIComponentManager**：UI组件管理器，负责UI更新和事件处理
3. **ContractDataGridComponent**：合约数据网格组件，负责表格显示和列动态调整
4. **AutoMonitorConfigDialog**：配置对话框，集成了配置同步功能

### 关键方法说明

1. **HandleBaseConfigurationChange**：处理基础配置变化
2. **SyncContractConfigsToBaseConfig**：同步合约配置到基础配置
3. **ForceRefreshColumns**：强制刷新列结构
4. **AnalyzeConfigurationChange**：分析配置变化

### 事件流程说明

1. **配置变化检测** → **分析变化** → **用户确认** → **执行同步** → **刷新UI**
2. **新合约添加** → **自动配置** → **刷新表格**
3. **手动同步** → **选择参数** → **批量执行** → **显示结果**
