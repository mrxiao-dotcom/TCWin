# 推仓止盈数据加载修复说明

## 🔍 问题分析

### 问题现象
- 自动盯盘页面中，推仓和止盈列显示为"-"
- 保本列正常显示数据（如0U、3U、1U等）
- 合约配置存在，但表格不显示具体数值

### 根本原因
**索引不匹配问题**：配置数据中的 `TierIndex` 从1开始（1,2,3,4），但显示属性查找时传入的索引从0开始（0,1,2,3），导致数据无法正确匹配。

## 🔧 修复内容

### 1. 修复显示属性查找逻辑
**文件**：`Models/AutoMonitorControlModels.cs`

**修复前**：
```csharp
private string GetAddPositionTierDisplay(int tierIndex)
{
    var condition = TriggerConditions.FirstOrDefault(c => 
        c.Type == TriggerConditionType.AddPosition && c.TierIndex == tierIndex);
    // tierIndex直接使用0,1,2,3，但配置数据TierIndex是1,2,3,4
}
```

**修复后**：
```csharp
private string GetAddPositionTierDisplay(int displayIndex)
{
    // 🔧 修复：配置数据TierIndex从1开始，显示索引从0开始，需要+1匹配
    var actualTierIndex = displayIndex + 1;
    var condition = TriggerConditions.FirstOrDefault(c => 
        c.Type == TriggerConditionType.AddPosition && c.TierIndex == actualTierIndex);
    // 现在查找1,2,3,4与配置数据匹配
}
```

### 2. 修复配置同步时的索引设置
**文件**：`Views/AutoMonitor/Components/ContractDataGridComponent.cs`

**修复前**：
```csharp
var newCondition = new TriggerConditionModel
{
    Type = TriggerConditionType.AddPosition,
    TierIndex = i, // i可能是0,1,2,3，导致TierIndex为0,1,2,3

```

**修复后**：
```csharp
// 🔧 修复：TierIndex从1开始，需要+1
var tierIndex = i + 1;
var newCondition = new TriggerConditionModel
{
    Type = TriggerConditionType.AddPosition,
    TierIndex = tierIndex, // 现在正确设置为1,2,3,4
    Description = $"推仓阶梯 {tierIndex}"
};
```
