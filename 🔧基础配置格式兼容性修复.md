# 🔧 基础配置格式兼容性修复

## 📋 问题描述

虽然我们统一了保存逻辑使用BaseConfigManager，但现有的配置文件仍然是旧格式，导致程序启动时找不到基础配置。

## 🔧 修复方案

### 方案1：增强BaseConfigManager的格式兼容性

**文件**: `Services/BaseConfigManager.cs`
**方法**: `LoadConfigurationsSync()` 第521行

**当前代码**（已有旧格式支持，但可能有问题）：
```csharp
// 🎯 首先尝试新格式（数组格式）
try
{
    configs = JsonSerializer.Deserialize<List<AutoMonitorConfig>>(json, ...);
}
catch (JsonException newFormatEx)
{
    // 🔄 如果新格式失败，尝试旧格式（对象格式）
    // ... 旧格式转换逻辑
}
```

**问题可能在于**：
1. 旧格式转换逻辑不完整
2. 转换后没有保存为新格式
3. 日志级别导致看不到转换过程

### 方案2：修复旧格式转换逻辑

在 `LoadConfigurationsSync()` 方法中，找到旧格式处理部分（约第548行），确保：

```csharp
// 检查是否是旧格式（包含accountConfigs）
if (root.TryGetProperty("accountConfigs", out var accountConfigsElement))
{

        var configJson = accountProperty.Value.GetRawText();

        {

        {
            _logger.LogError(saveEx, "❌ 保存新格式失败");
        }
    }
```

### 方案3：添加格式自动转换

在BaseConfigManager构造函数中添加格式检查和自动转换：

```csharp
private BaseConfigManager(ILogger<BaseConfigManager> logger, FilePathManager? filePathManager = null)
{
    _logger = logger;
    _filePathManager = filePathManager ?? new FilePathManager();
    _configFilePath = _filePathManager.GetBaseConfigsFilePath();
    Configurations = new ObservableCollection<AutoMonitorConfig>();
    
    _logger.LogDebug($"📁 基础配置文件路径: {_configFilePath}");
    
    // 🔧 【新增】启动时检查并转换格式
    CheckAndConvertFormat();
    
    // 🔧 【关键修复】使用同步加载，确保构造完成时配置已完全加载
    LoadConfigurationsSync();
}

/// <summary>
/// 检查并转换配置文件格式
/// </summary>
private void CheckAndConvertFormat()
{
    try
    {
        if (!File.Exists(_configFilePath))
        {
            _logger.LogInformation("配置文件不存在，无需转换");
            return;
        }
        
        var json = File.ReadAllText(_configFilePath);
        if (string.IsNullOrWhiteSpace(json))
        {
            _logger.LogInformation("配置文件为空，无需转换");
            return;
        }
        
        // 检查是否是旧格式
        if (json.TrimStart().StartsWith("{") && json.Contains("accountConfigs"))
        {
            _logger.LogWarning("🔍 检测到旧格式配置文件，开始自动转换...");
            
            try
            {
                using var document = JsonDocument.Parse(json);
                var root = document.RootElement;
                
                if (root.TryGetProperty("accountConfigs", out var accountConfigsElement))
                {
                    var newConfigs = new List<AutoMonitorConfig>();
                    
                    foreach (var accountProperty in accountConfigsElement.EnumerateObject())
                    {
                        var configJson = accountProperty.Value.GetRawText();
                        var config = JsonSerializer.Deserialize<AutoMonitorConfig>(configJson, new JsonSerializerOptions
                        {
                            PropertyNameCaseInsensitive = true
                        });
                        
                        if (config != null)
                        {
                            newConfigs.Add(config);
                        }
                    }
                    
                    if (newConfigs.Count > 0)
                    {
                        // 备份原文件
                        var backupPath = _configFilePath + ".backup." + DateTime.Now.ToString("yyyyMMdd_HHmmss");
                        File.Copy(_configFilePath, backupPath);
                        _logger.LogInformation($"✅ 原文件已备份到: {backupPath}");
                        
                        // 保存新格式
                        var newJson = JsonSerializer.Serialize(newConfigs, new JsonSerializerOptions
                        {
                            WriteIndented = true,
                            PropertyNamingPolicy = JsonNamingPolicy.CamelCase
                        });
                        
                        File.WriteAllText(_configFilePath, newJson, System.Text.Encoding.UTF8);
                        _logger.LogInformation($"✅ 配置格式转换完成，转换了 {newConfigs.Count} 个配置");
                    }
                }
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "❌ 配置格式转换失败");
            }
        }
        else if (json.TrimStart().StartsWith("["))
        {
            _logger.LogInformation("✅ 配置文件已是新格式（数组格式）");
        }
        else
        {
            _logger.LogWarning("⚠️ 无法识别配置文件格式");
        }
    }
    catch (Exception ex)
    {
        _logger.LogError(ex, "❌ 检查配置文件格式时发生错误");
    }
}
```
