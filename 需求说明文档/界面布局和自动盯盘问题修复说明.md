# 界面布局和自动盯盘问题修复说明

## 问题概述

根据用户反馈，存在以下三个主要问题：

1. **自动盯盘执行记录中出现不应该存在的BTC订单**
2. **保本止盈加仓过程中订单被错误平仓，可能是下单类型和方向错误**
3. **持仓列表和委托列表界面布局问题，存在过多空白空间需要滚动**

## 问题分析

### 1. 自动盯盘BTC订单问题

**可能原因**：
- 自动盯盘服务在扫描持仓时，可能获取到了历史持仓或API返回的所有合约数据
- 持仓过滤逻辑不够严格，包含了零持仓或已平仓的合约
- 执行历史记录没有正确清理已平仓的合约记录

**需要检查**：
- `AutoMonitorService.cs`中的`ScanPositionsAsync()`方法
- 持仓过滤条件是否正确（应该只处理`Math.Abs(position.PositionAmt) > 0`）
- 执行历史记录的清理机制

### 2. 保本止盈加仓平仓问题

**可能原因分析**：

#### A. 一键保本加仓功能问题
- **下单方向错误**：代码中加仓方向计算为 `position.PositionAmt > 0 ? "BUY" : "SELL"`，这是正确的
- **止损方向错误**：代码中止损方向计算为 `position.PositionAmt > 0 ? "SELL" : "BUY"`，这也是正确的
- **止损价格计算**：使用了缓冲机制，多头止损价 = 开仓价 + 缓冲，空头止损价 = 开仓价 - 缓冲

#### B. 自动盯盘推仓功能问题
查看`AutoMonitorService.cs`中的`ExecuteAddPositionAsync()`方法：
- 加仓方向：`position.PositionAmt > 0 ? "BUY" : "SELL"` ✅ 正确
- 止损方向：`position.PositionAmt > 0 ? "SELL" : "BUY"` ✅ 正确
- 但可能存在**PositionSide参数缺失**的问题

#### C. 可能的关键问题
1. **缺少PositionSide参数**：在下单时没有正确设置`PositionSide`参数
2. **ReduceOnly设置错误**：加仓订单不应该设置`ReduceOnly=true`
3. **止损委托冲突**：多个止损委托可能相互冲突

### 3. 界面布局问题

**当前设置**：
- 持仓列表：`MinHeight="150" MaxHeight="400"`
- 委托列表：`MinHeight="150" MaxHeight="400"`

**问题**：
- 固定的MaxHeight限制导致即使有空间也不能充分利用
- 需要动态调整高度以充分利用可用空间
- 应该让表格自动适应内容高度，在空间不足时才显示滚动条

## 修复方案

### 1. 修复自动盯盘BTC订单问题

需要在`AutoMonitorService.cs`中加强持仓过滤：

```csharp
// 只处理有实际持仓的合约
var activePositions = positions.Where(p => 
    Math.Abs(p.PositionAmt) > 0.0001m && // 数量过滤
    !string.IsNullOrEmpty(p.Symbol) &&   // 合约名称过滤
    p.MarkPrice > 0                       // 标记价格过滤
).ToList();
```

### 2. 修复下单参数问题

在所有下单请求中添加必要的参数：

```csharp
var orderRequest = new OrderRequest
{
    Symbol = symbol,
    Side = side,
    Type = "MARKET", // 或其他类型
    Quantity = quantity,
    PositionSide = position.PositionSideString, // 🔧 添加持仓方向
    // ReduceOnly 仅在平仓订单中设置为true
};
```

### 3. 修复界面布局问题

将固定高度改为动态高度：

```xml
<!-- 修改前 -->
<DataGrid MinHeight="150" MaxHeight="400">

<!-- 修改后 -->
<DataGrid MinHeight="120" MaxHeight="{Binding ActualHeight, 
    RelativeSource={RelativeSource AncestorType=Grid}, 
    Converter={StaticResource HeightToMaxHeightConverter}}">
```

或者使用更简单的方案，移除MaxHeight限制：

```xml
<DataGrid MinHeight="120" VerticalScrollBarVisibility="Auto">
```

## 修复优先级

1. **高优先级**：修复下单参数问题（防止错误平仓）
2. **中优先级**：修复界面布局问题（提升用户体验）
3. **低优先级**：修复BTC订单显示问题（不影响功能，仅影响显示）
