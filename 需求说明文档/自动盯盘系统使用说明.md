# 自动盯盘系统使用说明

## 📋 系统概述

自动盯盘系统是币安期货交易器的核心智能功能，提供24小时自动化的持仓管理。系统具备自动保本、智能推仓、保盈止损三大核心功能，帮助用户最大化盈利并控制风险。

## 🚀 快速开始

### 1. 启动自动盯盘

#### 第一步：选择账户
- 确保已在"账户配置"中设置好API密钥
- 在主界面选择要使用的交易账户
- 账户权益信息会自动显示

#### 第二步：配置自动盯盘
- 点击主界面的**"自动盯盘"**按钮
- 首次使用会弹出配置对话框
- 系统会根据账户权益自动生成智能默认配置

#### 第三步：确认配置并启动
- 检查配置参数是否合适
- 点击"确定"启动自动盯盘
- 按钮变红色显示"停止盯盘"表示运行中

### 2. 查看监控状态

#### 打开监控面板
- 点击**"查看监控"**按钮打开监控面板
- 面板显示运行状态、执行历史、合约状态等信息
- 每30秒自动刷新数据

## ⚙️ 配置详解

### 基础配置

#### 配置名称
- 为当前配置设置一个容易识别的名称
- 例如："保守策略"、"激进策略"等

#### 扫描间隔
- **建议值**: 30-60秒
- **最小值**: 10秒
- **说明**: 检查持仓状态的时间间隔，太短会增加系统负载

### 自动保本配置

#### 功能说明
- 当持仓浮盈达到设定值时，自动设置保本止损价格
- 确保至少不亏损本金，锁定基本安全

#### 关键参数
- **启用状态**: 勾选启用此功能
- **触发浮盈**: 达到多少浮盈时触发保本
  - **推荐值**: 账户权益的0.5%-1%
  - **示例**: 1000U账户设置5-10U
- **缓冲比例**: 保本价格的安全缓冲
  - **默认值**: 0.05% (防止价格波动误触发)

### 智能推仓配置（4个阶梯）

#### 功能说明
- 根据浮盈情况自动加仓，放大盈利效果
- 4个递进阶梯，风险和收益逐步增加

#### 阶梯配置详解

**阶梯1 - 初级推仓**
- **触发浮盈**: 默认20U
- **风险倍数**: 1.2倍（比初始仓位多投入20%）
- **止损比例**: 80%（允许亏损80%才止损）
- **适用场景**: 趋势确认，小幅加仓

**阶梯2 - 中级推仓**
- **触发浮盈**: 默认50U
- **风险倍数**: 1.5倍
- **止损比例**: 70%
- **适用场景**: 趋势强化，中等加仓

**阶梯3 - 高级推仓**
- **触发浮盈**: 默认100U
- **风险倍数**: 2.0倍
- **止损比例**: 60%
- **适用场景**: 强势趋势，大幅加仓

**阶梯4 - 极限推仓**
- **触发浮盈**: 默认200U
- **风险倍数**: 2.5倍
- **止损比例**: 50%
- **适用场景**: 超强趋势，最大加仓
- **注意**: 默认禁用，风险极高

#### 推仓策略建议
- **保守用户**: 只启用阶梯1-2
- **平衡用户**: 启用阶梯1-3，调低风险倍数
- **激进用户**: 全部启用，可适当提高触发条件

### 保盈止损配置（3个阶梯）

#### 功能说明
- 随着盈利增长，逐步提高止损价格
- 保护已获得的利润，防止盈利回撤

#### 阶梯配置详解

**阶梯1 - 基础保盈**
- **触发浮盈**: 30U
- **保护金额**: 10U
- **含义**: 浮盈30U时，保证至少盈利10U

**阶梯2 - 进阶保盈**
- **触发浮盈**: 80U
- **保护金额**: 30U
- **含义**: 浮盈80U时，保证至少盈利30U

**阶梯3 - 高级保盈**
- **触发浮盈**: 150U
- **保护金额**: 60U
- **含义**: 浮盈150U时，保证至少盈利60U

## 🎯 配置模板推荐

### 保守型配置（适合新手）
```
保本配置: 触发5U
推仓配置: 
  - 阶梯1: 15U触发，1.1倍风险，90%止损
  - 其他阶梯: 禁用
保盈配置:
  - 阶梯1: 20U触发，保护8U
  - 其他阶梯: 禁用
```

### 平衡型配置（适合有经验者）
```
保本配置: 触发8U
推仓配置:
  - 阶梯1: 20U触发，1.2倍风险，80%止损
  - 阶梯2: 45U触发，1.3倍风险，75%止损
  - 阶梯3: 禁用
保盈配置:
  - 阶梯1: 25U触发，保护10U
  - 阶梯2: 60U触发，保护25U  
  - 阶梯3: 禁用
```

### 激进型配置（适合专业用户）
```
保本配置: 触发10U
推仓配置: 全部启用（默认参数）
保盈配置: 全部启用（默认参数）
```

## 🔍 监控和管理

### 监控面板功能

#### 实时状态显示
- **运行状态**: 显示系统是否正在运行
- **运行时间**: 显示连续运行时长
- **活跃合约**: 当前监控的合约数量
- **执行统计**: 总执行次数和成功率

#### 合约执行状态
- **合约列表**: 显示所有被监控的合约
- **保本状态**: 显示是否已执行保本操作
- **推仓进度**: 显示推仓执行到第几阶梯
- **保盈进度**: 显示保盈执行到第几阶梯

#### 执行历史记录
- **时间**: 每次执行的具体时间
- **合约**: 执行的合约名称
- **类型**: 执行的操作类型（保本/推仓/保盈）
- **结果**: 执行成功或失败
- **浮盈**: 触发时的浮盈金额

### ⚠️ 重要注意事项

#### 使用前提
1. **确保账户API权限**:
   - 需要开启期货交易权限
   - 建议只在IP白名单模式下使用

2. **充足的账户余额**:
   - 确保有足够资金支持推仓操作
   - 建议账户余额至少是最大风险金的3倍

3. **网络连接稳定**:
   - 系统需要持续的网络连接
   - 网络中断会暂停监控（恢复后自动继续）

#### 风险控制
1. **不要过度依赖**:
   - 自动盯盘是辅助工具，不能替代人工判断
   - 遇到重大市场变化时应及时人工干预

2. **定期检查设置**:
   - 随着账户规模变化，及时调整配置参数
   - 关注系统执行日志，发现异常及时处理

3. **合理设置参数**:
   - 不要设置过于激进的参数
   - 风险倍数建议不超过3倍

## 🛠️ 故障排除

### 常见问题

#### 自动盯盘无法启动
**可能原因**:
- API密钥配置错误
- 网络连接问题
- 账户权限不足

**解决方法**:
1. 检查API密钥配置
2. 测试网络连接
3. 确认API权限设置

#### 执行失败率较高
**可能原因**:
- 网络延迟过高
- 市场波动剧烈
- 参数设置不合理

**解决方法**:
1. 增加扫描间隔
2. 调整触发条件
3. 降低风险倍数

#### 监控面板数据不更新
**可能原因**:
- 程序运行异常
- 内存不足
- 长时间运行导致的状态异常

**解决方法**:
1. 重启自动盯盘功能
2. 重启整个程序
3. 检查系统资源使用情况

### 日志和调试

#### 查看执行日志
- 监控面板中有详细的执行历史
- 可以查看每次操作的具体结果
- 失败操作会显示错误原因

#### 调试模式
- 主界面有"🔍调试"按钮（高级用户）
- 可以查看详细的系统状态信息
- 用于诊断复杂问题
