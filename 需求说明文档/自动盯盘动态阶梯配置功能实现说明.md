# 自动盯盘动态阶梯配置功能实现说明

## 功能概述

根据用户需求，为自动盯盘配置添加了动态增减阶梯的功能，让用户可以灵活调整推仓和止盈阶梯的数量，不再局限于固定的4个推仓阶梯和3个止盈阶梯。

## 新增功能

### 1. 推仓阶梯动态配置

**原来**：固定4个推仓阶梯
**现在**：可动态增减，默认4个，可无限增加

**新增控件**：
- `+ 增加推仓阶梯` 按钮：点击增加一个新的推仓阶梯
- `- 删除最后阶梯` 按钮：删除最后一个推仓阶梯（至少保留1个）
- 动态显示当前阶梯数量：`（X个阶梯）`

### 2. 止盈阶梯动态配置

**原来**：固定3个保盈止损阶梯
**现在**：可动态增减，默认3个，可无限增加

**新增控件**：
- `+ 增加止盈阶梯` 按钮：点击增加一个新的止盈阶梯
- `- 删除最后阶梯` 按钮：删除最后一个止盈阶梯（至少保留1个）
- 动态显示当前阶梯数量：`（X个阶梯）`

## 智能默认值生成

### 推仓阶梯智能计算
当用户点击"+ 增加推仓阶梯"时，系统会智能计算新阶梯的默认值：

```csharp
// 基于最后一个阶梯计算新值
var newTriggerAmount = lastStage.TriggerProfitAmount + 100;  // 触发值递增100U
var newRiskMultiplier = lastStage.RiskCapitalMultiplier;     // 风险倍数保持一致
var newStopLossPercentage = lastStage.StopLossPercentage;    // 止损比例保持一致
```

**示例**：
- 阶梯1：100U → 1.0倍 → 10%
- 阶梯2：200U → 1.0倍 → 10%
- 阶梯3：300U → 1.0倍 → 10%
- 阶梯4：400U → 1.0倍 → 10%
- **新增阶梯5**：500U → 1.0倍 → 10% ✨

### 止盈阶梯智能计算
当用户点击"+ 增加止盈阶梯"时，系统会智能计算新阶梯的默认值：

```csharp
// 基于最后一个阶梯计算新值
var newTriggerAmount = lastStage.TriggerProfitAmount + 1000;  // 触发值递增1000U
var newProtectionAmount = newTriggerAmount * 0.8m;           // 保护80%利润
```

**示例**：
- 阶梯1：1000U → 保护800U
- 阶梯2：2000U → 保护1600U
- 阶梯3：3000U → 保护2400U
- **新增阶梯4**：4000U → 保护3200U ✨

## 用户使用指南

### 增加推仓阶梯
1. 在"自动推仓设置"区域找到推仓阶梯表格
2. 点击表格下方的 `+ 增加推仓阶梯` 按钮
3. 系统自动添加新阶梯，触发值在最后一个阶梯基础上+100U
4. 可以手动修改新阶梯的参数（触发值、风险倍数、止损比例）
5. 勾选"启用"来激活该阶梯

### 删除推仓阶梯
1. 点击 `- 删除最后阶梯` 按钮
2. 系统弹出确认对话框
3. 点击"是"确认删除最后一个阶梯
4. 注意：至少需要保留1个阶梯，最后一个阶梯时删除按钮会禁用

### 增加止盈阶梯
1. 在"自动保盈止损设置"区域找到止盈阶梯表格
2. 点击表格下方的 `+ 增加止盈阶梯` 按钮
3. 系统自动添加新阶梯，触发值在最后一个阶梯基础上+1000U
4. 保护金额自动设为触发值的80%
5. 可以手动调整参数并勾选"启用"

### 删除止盈阶梯
1. 点击 `- 删除最后阶梯` 按钮
2. 确认删除操作
3. 至少保留1个止盈阶梯

这个动态阶梯配置功能大大提升了自动盯盘的灵活性：

1. **打破限制**：从固定阶梯数量到无限扩展
2. **智能体验**：自动计算默认值，减少配置负担
3. **安全可靠**：完善的验证和保护机制
4. **用户友好**：直观的操作界面和清晰的状态显示

用户现在可以根据自己的交易策略和资金规模，灵活配置任意数量的推仓和止盈阶梯，真正实现个性化的自动盯盘策略。
