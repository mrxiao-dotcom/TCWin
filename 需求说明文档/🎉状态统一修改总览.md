## 📝 关键原则

### **状态映射**
```
未触发 → ExecutionState = 0 (NotTriggered)
已执行 → ExecutionState = 2 (Executed)
```

### **符号系统**
```
未触发 → 符号: "-"
已执行 → 符号: "√"
```

### **保存逻辑**
```csharp
// 统一的保存模式
if (status == "√")
{
    stateService.UpdateExecutionStatus(contractKey, operationType, tierIndex, true, 0, "手动设置为executed");
}
else if (status == "-")
{
    stateService.UpdateExecutionStatus(contractKey, operationType, tierIndex, false, 0, "手动重置为waiting");
}
```

### **显示逻辑**
```csharp
// 统一的显示模式
config.StatusProperty = (tier?.ExecutionState == ExecutionState.Executed) ? "√" : "-";
```
