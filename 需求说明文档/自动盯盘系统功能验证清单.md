**测试准备**：设置较低的保本触发值（如2-5U）

- [ ] 开仓后，持仓有浮盈时系统能检测到

- [ ] 止损价格计算正确（入场价+缓冲）

#### 3.2 推仓功能

- [ ] 浮盈达到阶梯1触发条件时，系统自动加仓

- [ ] 推仓后设置相应的止损单
- [ ] 多个阶梯能按顺序执行
- [ ] 已执行的阶梯不会重复执行

#### 3.3 保盈功能
**测试准备**：设置较低的保盈触发值

- [ ] 浮盈达到保盈条件时，系统自动调整止损价格
- [ ] 保盈止损价格计算正确
- [ ] 多个保盈阶梯能正确执行
- [ ] 止损价格只会向有利方向调整

## 📝 测试注意事项

### 安全提醒
1. **使用最小资金测试**：避免大额资金风险
2. **设置合理的止损**：防止测试造成较大亏损
3. **实时监控**：测试期间需要人工监控
4. **准备应急预案**：出现异常时立即停止

### 测试技巧
1. **逐项验证**：不要跳过任何测试项目
2. **记录详细**：每个问题都要详细记录
3. **多次测试**：重要功能需要多次验证
4. **边界测试**：测试极端情况和边界值
