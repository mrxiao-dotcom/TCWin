# 监控面板多次推仓多次止盈空间预留优化说明

## 🚀 优化目标

为监控面板预留"推仓多次止盈多次"的空间，确保系统能够支持未来扩展到更多档位的推仓和保盈功能。

## 🔧 核心改进

### 1. 移除档位数量硬编码限制

**优化前**：
```csharp
// 硬编码限制档位数量
foreach (var tier in config.AddPositionConfig.Tiers.Take(4))  // 限制4个推仓档位
foreach (var tier in config.ProfitProtectionConfig.Tiers.Take(3))  // 限制3个保盈档位
```

**优化后**：
```csharp
// 支持动态数量的档位
foreach (var tier in config.AddPositionConfig.Tiers.OrderBy(t => t.TierIndex))  // 无限制推仓档位
foreach (var tier in config.ProfitProtectionConfig.Tiers.OrderBy(t => t.TierIndex))  // 无限制保盈档位
```

### 2. 引入滚动支持的布局设计

**新增滚动容器**：
```csharp
var scrollViewer = new ScrollViewer
{
    VerticalScrollBarVisibility = ScrollBarVisibility.Auto,
    HorizontalScrollBarVisibility = ScrollBarVisibility.Disabled,
    MaxHeight = 400, // 限制最大高度，超出时显示滚动条
};
```

**表格滚动支持**：
```csharp
// 推仓和保盈配置表格都支持独立滚动
MaxHeight = 200, // 单个表格最大高度
VerticalScrollBarVisibility = ScrollBarVisibility.Auto,
```

### 3. 动态进度显示系统

**新增动态属性**：
```csharp
public class ContractStateDisplayModel
{
    // 动态档位总数
    public int AddPositionTotalTiers { get; set; }
    public int ProfitProtectionTotalTiers { get; set; }
    
    // 动态进度显示
    public string AddPositionProgressDisplay => $"{AddPositionProgress}/{AddPositionTotalTiers}";
    public string ProfitProtectionProgressDisplay => $"{ProfitProtectionProgress}/{ProfitProtectionTotalTiers}";
}
```

**动态计算逻辑**：
```csharp
// 根据实际配置动态获取档位总数
var totalAddPositionTiers = config?.AddPositionConfig?.Tiers?.Count ?? 0;
var totalProfitProtectionTiers = config?.ProfitProtectionConfig?.Tiers?.Count ?? 0;

// 动态计算执行百分比
var maxPossibleExecutions = 1 + totalAddPositionTiers + totalProfitProtectionTiers;
```

### 4. 预留未来功能扩展区域

**扩展区域设计**：
```csharp
var futureExpandArea = new Border
{
    Background = new SolidColorBrush(Color.FromArgb(30, 100, 149, 237)), // 半透明蓝色
    Visibility = Visibility.Collapsed, // 默认隐藏，未来需要时显示
};
```

- ✅ **界面布局**：固定高度 → **可滚动高度**
