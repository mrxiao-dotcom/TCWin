## 🔍 故障诊断策略

### 场景A：立即验证失败
如果看到：
```
🔍【立即验证】推仓1设置后验证: 期望='950 -', 实际='-'
```
→ 说明`SetDynamicData`方法本身有问题，或者`GetDynamicData`返回错误

### 场景B：立即验证成功，但最终验证失败
如果看到：
```
🔍【立即验证】推仓1设置后验证: 期望='950 -', 实际='950 -'  ✅ 成功
... (其他处理)
🔍【PopulateConfigFromState结束】验证动态数据设置结果:
   推仓1动态数据: '-'  ❌ 最终失败
```
→ 说明数据在设置后被某个后续操作清空了

### 场景C：某些成功，某些失败
如果保本成功但推仓失败：
→ 说明推仓和保盈的处理逻辑与保本不同，可能有特殊的清空操作
