# ✅ 自动读取系统配置功能实现说明

## 功能概述

根据您的需求，在基础配置编辑器中，账户权益、风险次数应该直接从系统配置里读取，不需要用户再填写。

### 2. 后端代码修改（SimpleConfigEditorWindow.xaml.cs）

#### 添加RiskCapitalService注入
```csharp
public partial class SimpleConfigEditorWindow : Window
{
    private readonly RiskCapitalService _riskCapitalService;
    
    // 修改构造函数，支持MainViewModel注入
    public SimpleConfigEditorWindow(MainViewModel? mainViewModel = null)
    {
        InitializeComponent();
        
        // 初始化RiskCapitalService
        if (mainViewModel != null)
        {
            _riskCapitalService = new RiskCapitalService(logger, mainViewModel);
        }
        else
        {
            // 从Application.Current.MainWindow获取MainViewModel
            if (Application.Current.MainWindow is MainWindow mainWindow && 
                mainWindow.DataContext is MainViewModel vm)
            {
                _riskCapitalService = new RiskCapitalService(logger, vm);
            }
        }
        
        LoadConfigs();
        SetupUI();
        
        // 🔧 自动加载系统账户信息
        LoadSystemAccountInfo();
    }
}
```

#### 添加自动加载系统配置方法
```csharp
/// <summary>
/// 从系统配置加载账户权益和风险次数
/// </summary>
private void LoadSystemAccountInfo()
{
    try
    {
        if (_riskCapitalService != null)
        {
            // 从系统配置获取账户权益和风险次数
            var accountEquity = _riskCapitalService.GetCurrentAccountEquity();
            var riskTimes = _riskCapitalService.GetCurrentRiskCapitalTimes();
            
            // 自动填充到界面并设为只读
            AccountEquityTextBox.Text = accountEquity.ToString("F2");
            RiskTimesTextBox.Text = riskTimes.ToString();
            
            // 设为只读，不让用户修改
            AccountEquityTextBox.IsReadOnly = true;
            RiskTimesTextBox.IsReadOnly = true;
            AccountEquityTextBox.Background = System.Windows.Media.Brushes.LightGray;
            RiskTimesTextBox.Background = System.Windows.Media.Brushes.LightGray;
            
            // 自动计算风险金
            _currentRiskCapital = _riskCapitalService.CalculateRiskCapital(accountEquity, riskTimes);
            SingleRiskCapitalTextBox.Text = _currentRiskCapital.ToString("F2");
            
            // 更新按钮文本
            CalculateRiskCapitalButton.Content = "🔄 刷新系统数据";
        }
        else
        {
            // 如果服务不可用，显示提示并保持可编辑
            AccountEquityTextBox.Text = "1000.00";
            RiskTimesTextBox.Text = "10";
            CalculateRiskCapitalButton.Content = "🔄 计算风险金";
        }
    }
    catch (Exception ex)
    {
        MessageBox.Show($"加载系统账户信息失败：{ex.Message}\n请手动输入账户权益和风险次数。", 
                       "警告", MessageBoxButton.OK, MessageBoxImage.Warning);
    }
}
```

#### 修改计算按钮方法
```csharp
private void CalculateRiskCapitalButton_Click(object sender, RoutedEventArgs e)
{
    try
    {
        // 从系统配置重新获取最新的账户权益和风险次数
        if (_riskCapitalService != null)
        {
            var accountEquity = _riskCapitalService.GetCurrentAccountEquity();
            var riskTimes = _riskCapitalService.GetCurrentRiskCapitalTimes();
            
            // 更新界面显示
            AccountEquityTextBox.Text = accountEquity.ToString("F2");
            RiskTimesTextBox.Text = riskTimes.ToString();
            
            // 计算单倍风险金
            _currentRiskCapital = _riskCapitalService.CalculateRiskCapital(accountEquity, riskTimes);
            SingleRiskCapitalTextBox.Text = _currentRiskCapital.ToString("F2");
            
            MessageBox.Show($"系统数据刷新完成！\n\n账户权益：{accountEquity:F2} USDT\n风险次数：{riskTimes}\n单倍风险金：{_currentRiskCapital:F2} USDT\n\n这些数据已从系统配置自动获取。", 
                           "刷新完成", MessageBoxButton.OK, MessageBoxImage.Information);
        }
        else
        {
            MessageBox.Show("风险金服务不可用，无法从系统配置获取数据。", 
                           "服务不可用", MessageBoxButton.OK, MessageBoxImage.Warning);
        }
    }
    catch (Exception ex)
    {
        MessageBox.Show($"刷新系统数据时发生错误：{ex.Message}", 
                       "错误", MessageBoxButton.OK, MessageBoxImage.Error);
    }
}
```

### 3. 数据流程

#### 原始流程
```
用户手动输入账户权益 → 用户手动输入风险次数 → 点击计算按钮 → 计算风险金
```

#### 修改后流程
```
系统启动 → 自动从RiskCapitalService获取账户权益和风险次数 → 自动计算风险金 → 显示为只读
用户点击刷新按钮 → 重新从系统获取最新数据 → 更新显示
```

### 4. 用户体验改进

#### 界面状态
- **账户权益输入框**：设为只读，显示灰色背景，提示"从系统配置自动获取"
- **风险次数输入框**：设为只读，显示灰色背景，提示"从系统配置自动获取"
- **计算按钮**：改为"刷新系统数据"，点击时重新从系统获取最新数据

#### 错误处理
- 如果RiskCapitalService不可用，显示警告并保持原有手动输入模式
- 如果获取系统数据失败，提示用户检查连接状态
- 提供降级方案，确保功能可用性

### 5. 技术优势

#### 数据一致性
- 确保配置中使用的账户权益和风险次数与系统实际数据一致
- 避免用户手动输入错误导致的计算偏差

#### 用户体验
- 减少用户手动输入，降低操作复杂度
- 自动同步最新的账户数据
- 提供清晰的视觉反馈（只读状态、灰色背景）

#### 维护性
- 集中管理账户数据获取逻辑
- 统一的数据源，便于后续维护和升级

## 实施步骤

1. **修改XAML界面**：将账户权益和风险次数输入框设为只读，添加提示信息
2. **修改构造函数**：注入RiskCapitalService，支持MainViewModel参数
3. **添加自动加载方法**：在窗口初始化时自动从系统获取账户信息
4. **修改按钮方法**：将"计算风险金"改为"刷新系统数据"
5. **错误处理**：添加服务不可用时的降级处理
6. **测试验证**：确保在不同场景下功能正常工作

这样修改后，用户在基础配置编辑器中就不需要手动填写账户权益和风险次数了，这些数据会直接从系统配置中自动读取并显示。
