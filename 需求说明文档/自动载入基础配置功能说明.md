# 自动载入基础配置功能说明

## 🎯 功能概述

现在自动盯盘面板具备了**自动记忆和载入基础配置**的功能！如果您上次使用"狂飙"基础配置生成了合约配置，下次打开自动盯盘面板时，系统会自动载入"狂飙"配置对应的最新合约配置。

## 🔧 功能特点

### 1. 智能记忆上次配置
- ✅ **自动识别**：系统会记住您上次使用的基础配置（如"狂飙"、"保守"等）
- ✅ **账户独立**：每个账户的配置选择独立记忆，不会相互影响
- ✅ **持久保存**：配置选择会保存到文件，重启程序后依然有效

### 2. 自动载入合约配置
- ✅ **无需手动操作**：打开自动盯盘面板时自动载入，无需点击"载入持仓配置"
- ✅ **智能判断**：系统会自动判断载入已保存的合约配置或从持仓重新生成
- ✅ **表格同步**：自动生成与基础配置匹配的表格列结构

## 📋 使用流程

### 首次使用流程
1. **配置基础参数**：在主界面点击【盯盘参数配置】，创建/选择基础配置（如"狂飙"）
2. **打开监控面板**：点击【自动盯盘监控面板】
3. **系统自动载入**：面板会自动使用"狂飙"配置载入对应的合约配置
4. **开始监控**：直接点击【启动盯盘】即可

### 日常使用流程
1. **直接打开面板**：点击【自动盯盘监控面板】
2. **自动恢复配置**：系统自动载入上次使用的"狂飙"配置
3. **立即可用**：配置、表格结构、合约状态全部自动恢复

## 🔄 自动载入逻辑

### 载入优先级
1. **第一优先级**：已保存的合约配置文件
   - 如果存在对应基础配置的合约配置，直接载入
   - 保持之前的执行状态和个性化设置

2. **第二优先级**：从当前持仓生成
   - 如果无保存的配置但有活跃持仓，从持仓自动生成
   - 使用基础配置的参数创建新的合约配置

3. **第三优先级**：默认表格结构
   - 如果无配置也无持仓，至少载入表格列结构
   - 确保界面完整可用

### 自动载入过程
```
📂 检测到基础配置："狂飙"
🔄 开始自动载入对应的合约配置...

✅ 情况1：发现已保存的合约配置 3 个，自动载入
   - BTCUSDT_LONG: 保本已执行，推仓1已执行
   - ETHUSDT_LONG: 保本未触发
   - SOLUSDT_SHORT: 推仓1未触发

✅ 情况2：未发现保存配置，从 2 个活跃持仓自动生成
   - 基于"狂飙"配置参数
   - 所有状态重置为未触发

✅ 情况3：无活跃持仓，载入默认表格结构
   - 基于"狂飙"配置生成列结构
   - 等待新持仓时自动添加
```

## ⚙️ 技术实现细节

### 配置记忆机制
- **存储位置**：`%AppData%\BinanceFuturesTrader\automonitor_configs.json`
- **存储格式**：每个账户独立保存最后使用的基础配置
- **自动同步**：配置选择变化时立即保存到文件

### 自动载入机制
- **触发时机**：AutoMonitorDashboard窗口初始化时
- **异步处理**：使用Task.Run避免阻塞界面加载
- **线程安全**：所有UI更新都通过Dispatcher进行

### 错误处理
- **降级策略**：载入失败时自动使用默认配置
- **日志记录**：详细记录载入过程和错误信息
- **用户友好**：静默处理错误，不弹出干扰性提示

## 💡 使用建议

### 配置管理建议
1. **命名规范**：给基础配置起有意义的名字（如"狂飙"、"保守"、"激进"）
2. **定期检查**：偶尔检查配置是否符合当前市场情况
3. **备份重要配置**：重要的配置建议手动备份

### 操作建议
1. **首次配置后无需重复操作**：配置一次，长期使用
2. **切换配置时使用"基础配置重置"**：确保参数同步
3. **关注日志信息**：如有异常可查看日志了解详情

## 🆕 新增的便利性

### 之前的操作步骤
```
1. 打开自动盯盘面板
2. 点击【载入持仓配置】
3. 选择是否重置配置
4. 等待载入完成
5. 点击【启动盯盘】
```

### 现在的操作步骤
```
1. 打开自动盯盘面板（自动载入完成）
2. 点击【启动盯盘】
```

**减少了3个手动步骤，提升了使用体验！**

## 🔧 故障排除

### 如果自动载入失败
1. **检查配置**：确认主界面是否已配置基础参数
2. **查看日志**：检查日志文件中的错误信息
3. **手动载入**：可以点击【载入持仓配置】手动载入
4. **重新配置**：必要时重新在主界面配置参数

### 如果配置不符合预期
1. **使用重置功能**：点击【全部重置】按钮
2. **重新载入**：点击【载入持仓配置】并选择"基础配置重置"
3. **检查基础配置**：确认主界面的基础配置是否正确

这个功能大大简化了自动盯盘的使用流程，让您能够更快速、便捷地开始监控交易！
