# 基础配置编辑器风险金自动计算功能说明

## 🎯 功能概述

新增了强大的风险金自动计算和配置自动填写功能，让用户能够轻松根据账户权益和风险次数自动生成合理的自动盯盘配置。

## 🔧 功能特点

### **1. 智能风险金计算**
- 根据账户权益和风险次数自动计算单倍风险金
- 使用标准公式：`单倍风险金 = 账户权益 ÷ 风险次数`
- 实时显示计算结果，避免手动计算错误

### **2. 一键自动填写配置**
- 保本配置：自动设置为 `0.1倍风险金`
- 推仓配置：自动生成4个阶梯（1-4倍风险金）
- 保盈配置：自动生成3个阶梯（10倍、20倍、30倍风险金）

### **3. 智能默认参数**
- 推仓止损比例：默认10%
- 推仓风险倍数：默认1.0倍
- 保盈保护比例：默认80%

## 📊 使用流程

### **第1步：输入账户信息**
```
账户权益：10000    # 输入您的账户权益（USDT）
风险次数：10       # 输入风险次数（推荐8-20）
```

### **第2步：计算风险金**
点击 `🔄 计算风险金` 按钮，系统会：
- 验证输入的有效性
- 计算单倍风险金：10000 ÷ 10 = 1000 USDT
- 显示计算结果和详细信息

### **第3步：自动填写配置**
点击 `🎯 自动填写配置` 按钮，系统会：
- 进入编辑模式
- 显示详细的配置预览
- 一键填写所有配置项
