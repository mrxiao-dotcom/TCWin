# 分仓数量调整取整和快捷按钮优化说明

## 修改概述

本次修改主要解决了分仓止盈功能中的两个用户体验问题：
1. 数量调整按钮增减10%后需要进行取整处理
2. 快捷比例按钮的文字显示不够突出

## 功能优化详情

### 1. 数量调整按钮取整逻辑优化

#### 问题描述
用户在分仓面板中使用"+"和"-"按钮调整订单数量时，增减10%后的结果可能包含小数，导致前面的订单出现非整数数量，不符合整数分拆规则。

#### 解决方案
修改了`DecreaseQuantityButton_Click`和`IncreaseQuantityButton_Click`方法，加入了智能取整逻辑：

**减少数量逻辑：**
```csharp
// 如果是前面的订单（非最后一单），减少后需要取整
decimal adjustedDecrease;
if (index < _splitOrders.Count - 1)
{
    // 前面订单：减少后取整
    var newQuantity = originalQuantity - decreaseAmount;
    var integerQuantity = Math.Floor(newQuantity);
    adjustedDecrease = originalQuantity - Math.Max(integerQuantity, 1); // 最少保持1个
}
else
{
    // 最后一单：可以有小数
    adjustedDecrease = Math.Min(decreaseAmount, originalQuantity - 0.000001m);
}
```

**增加数量逻辑：**
```csharp
// 如果是前面的订单（非最后一单），增加后需要取整
decimal adjustedIncrease;
if (index < _splitOrders.Count - 1)
{
    // 前面订单：增加后取整
    var newQuantity = originalQuantity + increaseAmount;
    var integerQuantity = Math.Ceiling(newQuantity); // 向上取整确保增加
    adjustedIncrease = integerQuantity - originalQuantity;
}
else
{
    // 最后一单：可以有小数
    adjustedIncrease = increaseAmount;
}
```

#### 特点
- **前面订单**：严格按整数处理，减少时向下取整，增加时向上取整
- **最后一单**：可以包含小数部分，保持总量精确匹配
- **总量不变**：通过`ApplyIntegerSplitRule`方法重新分配，确保总量始终等于原持仓数量
- **最小保护**：减少时确保每个订单最少保持1个单位

### 2. 快捷比例按钮显示优化

#### 问题描述
用户反馈快捷比例按钮（90%、80%、50%、10%）只能看到颜色，文字显示不够突出，难以快速识别具体比例。

#### 解决方案
优化了快捷按钮的视觉样式：

**原来的按钮样式：**
```csharp
var profitButton = new Button
{
    Content = "90%",
    Width = 30,
    Height = 18,
    FontSize = 8,
    Background = Brushes.DarkGreen,
    Foreground = Brushes.White
};
```

**优化后的按钮样式：**
```csharp
var profitButton = new Button
{
    Content = "90%",
    Width = 35,           // 增大宽度
    Height = 20,          // 增大高度
    FontSize = 10,        // 增大字体
    FontWeight = FontWeights.Bold,  // 字体加粗
    Background = Brushes.DarkGreen,
    Foreground = Brushes.White,
    BorderBrush = Brushes.White,    // 添加白色边框
    BorderThickness = new Thickness(1) // 1像素边框
};
```

#### 优化效果
- **尺寸增大**：按钮从30x18增加到35x20，提供更大的点击区域
- **字体优化**：字体从8号增加到10号，并设置为粗体显示
- **边框增强**：添加白色边框，增强按钮的立体感和可识别性
- **视觉突出**：文字在彩色背景上更加醒目，易于快速识别

### 3. 颜色编码保持

快捷按钮继续使用直观的颜色编码：
- **90%**：深绿色 (DarkGreen) - 表示高比例保留
- **80%**：绿色 (Green) - 表示较高比例保留  
- **50%**：橙色 (Orange) - 表示中等比例保留
- **10%**：红色 (Red) - 表示低比例保留
