### 2. AutoMonitorScanExecutor.cs 异步警告修复
**问题**: 异步方法缺少 `await` 运算符

**修复1**: `CleanupClosedPositions` 方法
```csharp
// ❌ 修复前
private async Task CleanupClosedPositions(...)
await CleanupClosedPositions(contractStates, activeContractKeys);

// ✅ 修复后
private void CleanupClosedPositions(...)
CleanupClosedPositions(contractStates, activeContractKeys);
```

**修复2**: `GetOrCreateContractState` 方法
```csharp
// ❌ 修复前
private async Task<ContractMonitoringState> GetOrCreateContractState(...)
var contractState = await GetOrCreateContractState(contractStates, contractKey, position);

// ✅ 修复后
private ContractMonitoringState GetOrCreateContractState(...)
var contractState = GetOrCreateContractState(contractStates, contractKey, position);
```
