## 🎯 功能概述

根据用户需求，成功实现了在新建配置时自动读取账户权益、设置风险次数并将保本目标金额默认为1倍风险金的功能。

## ✅ **实现的核心功能**

### **1. 自动读取账户权益**
- **功能**：新建配置时自动从主窗口获取当前账户权益
- **实现**：添加了 `GetCurrentAccountEquity()` 方法，通过反射获取MainWindow的账户信息
- **回退机制**：如果无法获取，使用默认值1000 USDT

### **2. 自动设置风险次数**
- **功能**：提供默认的风险次数设置
- **实现**：添加了 `GetCurrentRiskTimes()` 方法，返回默认值10
- **扩展性**：可以从配置文件或其他来源读取个性化设置

### **3. 保本配置调整为1倍风险金**
- **原设置**：保本触发金额 = 风险金 × 0.1 (0.1倍)
- **新设置**：保本触发金额 = 风险金 × 1.0 (1倍)
- **影响范围**：智能配置生成器和自动填写功能

### **4. 智能配置预览**
- **新建时**：自动计算并显示风险金
- **智能提示**：显示详细的配置信息和建议
- **用户确认**：提供清晰的配置预览

// 新增：获取账户权益的方法
private decimal GetCurrentAccountEquity()
{
    try
    {
        var appWindow = Application.Current.MainWindow;
        if (appWindow != null)
        {
            var accountInfoProperty = appWindow.GetType().GetProperty("AccountInfo");
            if (accountInfoProperty != null)
            {
                var accountInfo = accountInfoProperty.GetValue(appWindow);
                if (accountInfo != null)
                {
                    var totalEquityProperty = accountInfo.GetType().GetProperty("TotalWalletBalance");
                    if (totalEquityProperty != null && totalEquityProperty.GetValue(accountInfo) is decimal equity)
                    {
                        return equity;
                    }
                }
            }
        }
        return 1000m; // 默认值
    }
    catch
    {
        return 1000m; // 获取失败时返回默认值
    }
}

}
