# 推仓加仓数量计算公式修正说明

## 🚨 问题发现

用户发现自动盯盘中盈利加仓的数量计算公式存在错误，需要重新设计计算逻辑。

## ❌ 原有错误公式

### 错误的计算逻辑

```csharp
// 错误的计算方式
var addPositionAmount = singleRiskCapital * stage.RiskMultiplier;
var addQuantity = addPositionAmount / latestPrice;
```

### 问题分析

1. **风险控制不合理**：直接用风险金乘以倍数作为下单金额
2. **止损比例未参与计算**：忽略了配置的止损比例参数
3. **实际风险暴露不可控**：可能导致实际止损金额远超预期风险金

## ✅ 修正后的正确公式

### 正确的计算逻辑

```csharp
// 修正后的计算方式
// 1. 计算账户的单笔风险金
var singleRiskCapital = accountEquity / riskTimes;

// 2. 从配置获取当前阶梯的参数
var riskMultiplier = stage.RiskMultiplier;  // 风险倍数（例如：1.0倍）
var stopLossRatio = stage.StopLossRatio;    // 止损比例（例如：0.10 = 10%）

// 3. 计算加仓货值 = 风险倍数 * 单笔风险金 / 止损比例
var addPositionValue = riskMultiplier * singleRiskCapital / stopLossRatio;

// 4. 计算加仓数量 = 加仓货值 / 币的单价
var addQuantity = addPositionValue / latestPrice;
```

### 公式详解

#### 核心思想
- **风险金**：用户愿意承受的最大亏损金额
- **止损比例**：价格回撤多少时触发止损
- **货值**：基于风险承受能力计算的持仓价值

#### 计算步骤

**第1步：基础参数**
- 账户权益 = 1000U
- 风险倍数 = 8（即单笔风险金 = 125U）
- 阶梯配置：风险倍数1.0倍，止损比例10%

**第2步：货值计算**
```
加仓货值 = 1.0 × 125U ÷ 0.10 = 1250U
```

**第3步：数量计算**
```
假设BTC价格 = 50000U
加仓数量 = 1250U ÷ 50000U = 0.025 BTC
```

**第4步：风险验证**
```
如果价格从50000跌到45000（下跌10%）
实际亏损 = 0.025 × (50000 - 45000) = 125U
= 正好等于预设的单笔风险金
```

## 🎯 修正效果对比

### 实际案例分析

假设：
- 账户权益：1000U
- 风险倍数：8（单笔风险金125U）
- 推仓配置：1倍风险金，10%止损
- BTC价格：50000U

#### 错误公式结果
```
加仓金额 = 125U × 1.0 = 125U
加仓数量 = 125U ÷ 50000U = 0.0025 BTC
如果价格跌10%到45000U：
实际亏损 = 0.0025 × 5000U = 12.5U
实际风险 = 12.5U（远小于预期的125U）
```

#### 正确公式结果
```
加仓货值 = 1.0 × 125U ÷ 0.10 = 1250U  
加仓数量 = 1250U ÷ 50000U = 0.025 BTC
如果价格跌10%到45000U：
实际亏损 = 0.025 × 5000U = 125U
实际风险 = 125U（正好等于预期）
```
