# 最简单的监控面板改进指南

## 🎯 目标
让您立即在监控面板窗口标题栏看到：
- ✅ 实时时间显示
- ✅ 运行状态（🟢运行中/🔴已停止）
- ✅ 扫描倒计时
- ✅ 确认系统正常工作

## 🚀 最简单的修改方案

### 第一步：定位文件
打开文件：`Views/AutoMonitorDashboard.xaml.cs`

### 第二步：找到构造函数
找到 `public AutoMonitorDashboard(AutoMonitorService autoMonitorService, ILogger logger)` 构造函数

### 第三步：在构造函数末尾添加代码

在构造函数的最后几行（在 `_logger.LogInformation("🖥️ 自动盯盘监控面板已初始化");` 之前）添加以下代码：

```csharp
// 🔧 简单改进：实时更新窗口标题显示监控状态
var titleTimer = new DispatcherTimer { Interval = TimeSpan.FromSeconds(1) };
titleTimer.Tick += (s, e) =>
{
    try
    {
        var isRunning = _autoMonitorService?.IsRunning ?? false;
        var status = isRunning ? "🟢运行中" : "🔴已停止";
        var time = DateTime.Now.ToString("HH:mm:ss");
        Title = $"🔍 自动盯盘监控面板 - {status} | {time}";
    }
    catch (Exception ex)
    {
        Title = "🔍 自动盯盘监控面板 - 状态异常";
        _logger.LogError(ex, "更新窗口标题时发生错误");
    }
};
titleTimer.Start();
```
