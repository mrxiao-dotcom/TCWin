### ✅ **问题1：双击编辑保存异常 - contractState为null**

**问题描述**：
- 用户双击编辑统一配置状态时，保存报异常
- 日志显示：`**contractState** 是 null`

**根本原因**：
```csharp
// ContractConfigEditDialog.xaml.cs 第516行
if (allStates.TryGetValue(contractKey, out var contractState))
{
    // contractState只在这个if块内有效
}

// 第530行：这里contractState已经超出作用域，变成null了！
contractState.BreakEvenConfig.ExecutionState = ExecutionState.Executed;  // ❌ 报错
```

**修复方案**：
```csharp
// 修改为提前检查并抛出异常
if (!allStates.TryGetValue(contractKey, out var contractState))
{
    _logger?.LogError($"❌ 无法找到合约状态: {contractKey}");
    _logger?.LogError($"❌ 可用的合约键: {string.Join(", ", allStates.Keys)}");
    throw new InvalidOperationException($"无法找到合约状态: {contractKey}");
}

// 现在contractState在整个方法范围内都有效
contractState.BreakEvenConfig.ExecutionState = ExecutionState.Executed;  // ✅ 正常
```

### ✅ **问题2：保盈2、3档没有显示"-"**

**问题描述**：
- UI界面中保盈2、3档位列没有显示出来
- 用户看不到这两列的"-"状态

**根本原因**：
UI列是动态生成的，生成逻辑在`Views/AutoMonitorConfigWindowSimple.xaml.cs`第2481-2501行：

```csharp
// 添加保盈列
if (_currentConfig.ProfitProtectionConfig?.IsEnabled == true && _currentConfig.ProfitProtectionConfig.Tiers?.Count > 0)
{
    foreach (var tier in _currentConfig.ProfitProtectionConfig.Tiers.OrderBy(t => t.TierIndex))
    {
        var column = new DataGridTextColumn
        {
            Header = $"保盈{tier.TierIndex}档",
            Width = new DataGridLength(90)
        };
        column.Binding = new Binding($"DynamicProfit{tier.TierIndex}");
        ContractConfigDataGrid.Columns.Insert(insertIndex++, column);
    }
}
```

**关键发现**：
- 如果基础配置中`ProfitProtectionConfig.Tiers`只有1个元素，就只生成1列
- 如果有2个元素，就只生成2列
- 必须有3个元素，才能生成3列

**基础配置检查**：
在`Services/BaseConfigManager.cs`第731-733行确实生成了3个保盈阶梯：
```csharp
return new List<ProfitProtectionTier>
{
    new ProfitProtectionTier { TierIndex = 1, TriggerProfitAmount = Math.Round(riskCapital * 10m, 0, MidpointRounding.AwayFromZero), ProtectionAmount = Math.Round(riskCapital * 10m * 0.8m, 0, MidpointRounding.AwayFromZero), IsEnabled = true },
    new ProfitProtectionTier { TierIndex = 2, TriggerProfitAmount = Math.Round(riskCapital * 20m, 0, MidpointRounding.AwayFromZero), ProtectionAmount = Math.Round(riskCapital * 20m * 0.8m, 0, MidpointRounding.AwayFromZero), IsEnabled = true },
    new ProfitProtectionTier { TierIndex = 3, TriggerProfitAmount = Math.Round(riskCapital * 30m, 0, MidpointRounding.AwayFromZero), ProtectionAmount = Math.Round(riskCapital * 30m * 0.8m, 0, MidpointRounding.AwayFromZero), IsEnabled = true }
};
```

**可能的问题**：
1. 当前使用的基础配置不是通过`CreateDefaultProfitProtectionTiers`生成的
2. 基础配置被某个地方修改，删除了部分阶梯
3. 状态文件中的配置与基础配置不同步

## 🔧 完整的解决方案

### **方案1：重新生成完整的基础配置**

创建一个新的基础配置，确保包含3个保盈阶梯：

```csharp
// 在BaseConfigManager中强制确保保盈配置有3个阶梯
private void EnsureProfitProtectionTiers(AutoMonitorConfig config)
{
    if (config.ProfitProtectionConfig?.Tiers == null)
    {
        config.ProfitProtectionConfig.Tiers = new List<ProfitProtectionTier>();
    }
    
    // 确保有3个阶梯
    for (int i = 1; i <= 3; i++)
    {
        if (!config.ProfitProtectionConfig.Tiers.Any(t => t.TierIndex == i))
        {
            var riskCapital = 1000m / 10; // 默认值
            config.ProfitProtectionConfig.Tiers.Add(new ProfitProtectionTier 
            { 
                TierIndex = i, 
                TriggerProfitAmount = Math.Round(riskCapital * i * 10m, 0, MidpointRounding.AwayFromZero), 
                ProtectionAmount = Math.Round(riskCapital * i * 10m * 0.8m, 0, MidpointRounding.AwayFromZero), 
                IsEnabled = true 
            });
        }
    }
}
```
