# 自动盯盘加仓数量计算修复说明

## 问题描述

用户反馈自动盯盘功能中，触发第一档盈利加仓时计算的数量不正确。需要按照以下正确的计算方法修复：

1. 计算单笔风险金：账户权益/风险次数=单笔风险金
2. 根据设置的止损比例，用单笔风险金计算出本次增仓的货值
3. 本次加仓的数量=增仓货值/合约单价
4. 根据该合约的下单要求，对数量进行规范化，然后下市价单，并且在配置数据中做好记录

## 原有计算逻辑（错误）

在`Services/AutoMonitorService.cs`的`ExecuteAddPositionAsync`方法中：

```csharp
// 错误的计算方法
var accountEquity = _mainViewModel.AccountInfo?.TotalEquity ?? 0;
var riskTimes = _mainViewModel.SelectedAccount?.RiskCapitalTimes ?? 8;
var riskCapital = accountEquity / riskTimes * stage.RiskMultiplier; // ❌ 直接乘以风险倍数

var latestPrice = await _binanceService.GetLatestPriceAsync(position.Symbol);
var addQuantity = riskCapital / latestPrice; // ❌ 直接用风险金除以价格
```

### 问题分析

1. **风险金计算错误**：直接将单笔风险金乘以`stage.RiskMultiplier`，没有考虑止损比例
2. **货值计算缺失**：没有根据止损比例计算实际可承受的仓位货值
3. **数量计算简化**：直接用风险金除以价格，忽略了止损比例对仓位规模的影响

## 修复后的计算逻辑（正确）

### 1. 计算单笔风险金
```csharp
// 1. 计算单笔风险金：账户权益/风险次数=单笔风险金
var accountEquity = _mainViewModel.AccountInfo?.TotalEquity ?? 0;
var riskTimes = _mainViewModel.SelectedAccount?.RiskCapitalTimes ?? 8;
var singleRiskCapital = accountEquity / riskTimes;
```

**说明**：这是账户允许单次交易承受的最大亏损金额。

### 2. 计算增仓货值
```csharp
// 2. 根据设置的止损比例，用单笔风险金计算出本次增仓的货值
var stopLossRatio = stage.StopLossRatio; // 这里是小数形式，如0.1表示10%
var positionValue = singleRiskCapital / stopLossRatio;
```

**说明**：根据止损比例反推可以持有的最大仓位货值。

### 3. 计算加仓数量
```csharp
// 3. 获取最新价格
var latestPrice = await _binanceService.GetLatestPriceAsync(position.Symbol);

// 4. 本次加仓的数量=增仓货值/合约单价
var addQuantity = positionValue / latestPrice;
```

**说明**：用货值除以合约单价得到实际的加仓数量。

### 4. 添加详细日志
```csharp
_logger.LogInformation($"💰 加仓计算详情: 账户权益={accountEquity:F2}U, 风险次数={riskTimes}, 单笔风险金={singleRiskCapital:F2}U, 止损比例={stopLossRatio * 100:F1}%, 增仓货值={positionValue:F2}U, 合约单价={latestPrice:F4}, 加仓数量={addQuantity:F8}");
```

## 计算示例对比

### 假设条件
- 账户权益：1000 USDT
- 风险次数：10
- 止损比例：10% (0.1)
- 合约单价：50000 USDT (如BTCUSDT)

### 修复前（错误计算）
```
风险金 = 1000 / 10 * 1.0 = 100 USDT
加仓数量 = 100 / 50000 = 0.002 BTC
```

### 修复后（正确计算）
```
单笔风险金 = 1000 / 10 = 100 USDT
增仓货值 = 100 / 0.1 = 1000 USDT
加仓数量 = 1000 / 50000 = 0.02 BTC
```

### 对比结果
- **修复前**：加仓数量 0.002 BTC，货值 100 USDT
- **修复后**：加仓数量 0.02 BTC，货值 1000 USDT
- **差异**：修复后的加仓数量是修复前的**10倍**

## 计算逻辑验证

### 风险控制验证
以修复后的计算为例：
- 加仓数量：0.02 BTC
- 加仓价格：50000 USDT
- 加仓货值：0.02 × 50000 = 1000 USDT
- 止损比例：10%
- 最大亏损：1000 × 0.1 = 100 USDT ✅（等于单笔风险金）

### 数学公式验证
```
货值 = 风险金 ÷ 止损比例
数量 = 货值 ÷ 单价
最大亏损 = 货值 × 止损比例 = 风险金 ✅
```

// 检查交易规则
var (minQty, maxQty, stepSize, _, _) = await _binanceService.GetSymbolTradingRulesAsync(position.Symbol);
