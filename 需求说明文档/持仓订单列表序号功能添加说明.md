# 持仓订单列表序号功能添加说明

## 🎯 功能需求

用户希望在持仓订单列表前面加一个序号列，能够清楚地知道目前有多少持仓。

## 🛠️ 实现方案

### 1. XAML界面修改

在`MainWindow.xaml`中为持仓列表添加序号列：

#### A. 添加序号列定义
```xml
<!-- 序号列 -->
<DataGridTemplateColumn Header="序号" Width="45" MinWidth="40">
    <DataGridTemplateColumn.CellTemplate>
        <DataTemplate>
            <TextBlock Text="{Binding RelativeSource={RelativeSource AncestorType=DataGridRow}, Path=Header}" 
                      HorizontalAlignment="Center"
                      VerticalAlignment="Center"
                      FontWeight="Bold"
                      FontSize="12"
                      Foreground="DarkBlue"/>
        </DataTemplate>
    </DataGridTemplateColumn.CellTemplate>
</DataGridTemplateColumn>
```

#### B. 为DataGrid添加LoadingRow事件
```xml
<DataGrid x:Name="PositionsDataGrid"
         ItemsSource="{Binding Positions}"
         ...
         LoadingRow="PositionsDataGrid_LoadingRow">
```

### 2. 后台代码实现

在`MainWindow.xaml.cs`中添加行加载事件处理：

```csharp
/// <summary>
/// 持仓列表行加载事件 - 设置序号
/// </summary>
private void PositionsDataGrid_LoadingRow(object sender, DataGridRowEventArgs e)
{
    // 设置行号（从1开始）
    e.Row.Header = (e.Row.GetIndex() + 1).ToString();
}
```

## 🎨 界面效果

### 列布局调整
- **序号列**：宽度45px，最小40px
- **选择列**：保持原有的45px宽度
- **序号显示**：居中对齐，深蓝色，粗体显示

### 功能特点
1. **自动计数**：序号从1开始自动递增
2. **动态更新**：当持仓列表刷新时，序号自动更新
3. **清晰显示**：用户可以一眼看出当前有多少个持仓
4. **视觉友好**：序号采用深蓝色和粗体，便于识别

## 📊 技术实现细节

### 1. 序号绑定方式
使用WPF的`DataGridRow.Header`属性来存储序号，这是一种标准的WPF DataGrid序号实现方式。

### 2. 事件触发时机
- **LoadingRow事件**：每当DataGrid加载新行时触发
- **自动更新**：数据源变化时会重新加载所有行，序号自动重新计算

### 3. 性能考虑
- 使用`GetIndex()`方法获取当前行索引，性能开销很小
- 序号计算在行加载时进行，不会影响数据绑定性能
