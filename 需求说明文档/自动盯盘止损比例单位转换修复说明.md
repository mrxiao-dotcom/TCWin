# 自动盯盘止损比例单位转换修复说明

## 问题描述

用户反馈：**自动监控功能中，触发盈利加仓的时候，止损比例用了10%，但填写到止损比例时，变成了0.1，这样止损比例变成了0.1%，这样不正确**

## 问题分析

### 根本原因

这是一个**单位转换错误**，涉及两个层面的问题：

1. **数据存储与显示不一致**
2. **转换逻辑缺失**

### 问题详情

#### 1. 配置存储格式不一致

**配置对话框默认值**（`AutoMonitorConfigDialog.xaml.cs`）：
```csharp
// 以百分比数值形式存储和显示
StopLossPercentage = 80  // 表示80%
StopLossPercentage = 70  // 表示70%
StopLossPercentage = 60  // 表示60%
StopLossPercentage = 50  // 表示50%
```

**配置模型默认值**（`AutoMonitorConfig.cs`）：
```csharp
// 修复前：以小数形式存储（错误的默认值）
StopLossRatio = 0.02m   // 表示2%（应该是80%）
StopLossRatio = 0.025m  // 表示2.5%（应该是70%）
StopLossRatio = 0.03m   // 表示3%（应该是60%）
StopLossRatio = 0.035m  // 表示3.5%（应该是50%）
```

#### 2. 转换逻辑缺失

**问题代码**（`AutoMonitorService.cs`）：
```csharp
// 直接将小数值赋给期望百分比值的属性
_mainViewModel.StopLossRatio = stage.StopLossRatio; // 0.1 → 0.1
```

**期望行为**：
- `stage.StopLossRatio = 0.1`（10%的小数表示）
- `_mainViewModel.StopLossRatio = 10`（10%的百分比表示）

## 修复方案

### 1. 修复转换逻辑

**文件**：`Services/AutoMonitorService.cs`
**位置**：`ExecuteAddPositionAsync`方法

**修复前**：
```csharp
_mainViewModel.StopLossRatio = stage.StopLossRatio;
```

**修复后**：
```csharp
// 将小数形式的止损比例转换为百分比形式（0.1 → 10）
_mainViewModel.StopLossRatio = stage.StopLossRatio * 100;
```

### 2. 统一默认配置值

**文件**：`Models/AutoMonitorConfig.cs`
**位置**：`AutoAddPositionConfig`类的默认配置

**修复前**：
```csharp
new AddPositionTier { TierIndex = 1, TriggerProfitAmount = 20.0m, RiskMultiplier = 1.5m, StopLossRatio = 0.02m },
new AddPositionTier { TierIndex = 2, TriggerProfitAmount = 50.0m, RiskMultiplier = 2.0m, StopLossRatio = 0.025m },
new AddPositionTier { TierIndex = 3, TriggerProfitAmount = 100.0m, RiskMultiplier = 2.5m, StopLossRatio = 0.03m },
new AddPositionTier { TierIndex = 4, TriggerProfitAmount = 200.0m, RiskMultiplier = 3.0m, StopLossRatio = 0.035m }
```

**修复后**：
```csharp
new AddPositionTier { TierIndex = 1, TriggerProfitAmount = 20.0m, RiskMultiplier = 1.2m, StopLossRatio = 0.80m },
new AddPositionTier { TierIndex = 2, TriggerProfitAmount = 50.0m, RiskMultiplier = 1.5m, StopLossRatio = 0.70m },
new AddPositionTier { TierIndex = 3, TriggerProfitAmount = 100.0m, RiskMultiplier = 2.0m, StopLossRatio = 0.60m },
new AddPositionTier { TierIndex = 4, TriggerProfitAmount = 200.0m, RiskMultiplier = 2.5m, StopLossRatio = 0.50m }
```

## 数据流转过程

### 修复后的正确流程

1. **配置对话框输入**：用户输入`80`（表示80%）
2. **保存到配置**：`StopLossRatio = 80 / 100 = 0.8`（小数形式存储）
3. **自动监控使用**：`_mainViewModel.StopLossRatio = 0.8 * 100 = 80`（百分比形式）
4. **界面显示**：显示为`80%`止损比例

### 各组件的数据格式约定

| 组件 | 格式 | 示例 | 说明 |
|------|------|------|------|
| **配置对话框输入** | 百分比数值 | `80` | 用户输入80表示80% |
| **配置模型存储** | 小数形式 | `0.8` | 数据库/配置文件存储 |
| **MainViewModel** | 百分比数值 | `80` | 业务逻辑使用 |
| **界面显示** | 百分比文本 | `80%` | 用户看到的显示 |

## 技术细节

### 转换公式

```csharp
// 配置对话框 → 配置模型
configModel.StopLossRatio = dialogInput.StopLossPercentage / 100;

// 配置模型 → MainViewModel  
mainViewModel.StopLossRatio = configModel.StopLossRatio * 100;

// MainViewModel → 下单计算
stopLossPercentage = mainViewModel.StopLossRatio / 100; // 转回小数用于计算
```

### 一致性保证

1. **存储格式统一**：配置文件中始终以小数形式存储（0.8表示80%）
2. **显示格式统一**：界面上始终以百分比形式显示（80%）
3. **转换点明确**：在数据流转的关键点进行格式转换
