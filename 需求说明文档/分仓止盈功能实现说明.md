# 分仓止盈功能实现说明

## 功能概述

分仓止盈是一个高级的风险管理工具，允许用户将一个大持仓拆分成多个小持仓，为每个小持仓设置不同的止盈价格，实现分批获利的策略。这样可以在价格波动中获得更好的风险收益平衡。

## 功能特点

### 1. 智能分仓拆分
- **默认平均分配**：输入拆分数量（默认2单），系统自动平均分配数量和浮盈
- **灵活调整数量**：可以手动调整每个分拆订单的数量，系统自动保持总量不变
- **精确数量控制**：最后一个订单的数量会自动调整，确保总数量与原持仓完全匹配

### 2. 目标浮盈设置
- **默认保守策略**：每个分拆订单的默认目标浮盈为当前浮盈的80%
- **灵活自定义**：可以为每个分拆订单设置不同的目标浮盈金额
- **智能验证**：目标浮盈必须小于当前浮盈，确保策略合理性

### 3. 自动价格计算
- **精确计算**：根据目标浮盈自动计算止盈价格
- **多空适配**：自动适应做多和做空不同方向的计算公式
- **价格精度**：自动调整到4位小数精度，符合交易所要求

## 使用流程

### 步骤1：选择持仓
- 在持仓列表中选择一个**有浮盈**的持仓
- 点击"分仓止盈"按钮

### 步骤2：设置分拆参数
1. **输入拆分数量**：默认2，最多10个分拆订单
2. **查看分配结果**：系统自动显示每个分拆订单的数量和当前浮盈
3. **调整数量**（可选）：如果需要，可以手动调整各分拆订单的数量

### 步骤3：设置目标浮盈
1. **设置目标浮盈**：为每个分拆订单输入期望的目标浮盈金额
2. **计算止盈价**：点击"计算价格"按钮，系统自动计算止盈价格
3. **预览结果**：点击"预览计算"查看完整的分仓止盈计划

### 步骤4：确认执行
- 检查所有参数无误后，点击"确定执行"
- 系统将提交多个限价止盈订单
- 自动刷新委托单列表显示新的订单

## 计算公式

### 做多持仓
```
目标止盈价 = 开仓价 + (目标浮盈 / 数量)
```

### 做空持仓
```
目标止盈价 = 开仓价 - (目标浮盈 / 数量)
```

## 总结

分仓止盈功能为交易者提供了一个强大而灵活的风险管理工具。通过将大持仓拆分成多个小持仓，用户可以：

- **降低风险**：不必一次性平掉全部持仓
- **提高收益**：在不同价位分批获利
- **增强控制**：更精细的仓位管理策略
- **减少遗憾**：避免过早或过晚平仓的后悔

这个功能特别适合中长期持仓的用户，在牛市或强势行情中可以最大化收益，同时控制回调风险。
