# 🎯 推仓阶梯状态修改指南

## 📋 修改目标
将推仓各个阶梯的状态从英文的 waiting/executing/executed 改为中文的两个状态：
- ✅ **已执行** (符号: √)
- ➖ **未触发** (符号: -)

### 2. **Views/ContractConfigEditDialog.xaml.cs**
在SaveContractConfigToFile方法中，添加推仓阶梯状态的保存逻辑：

```csharp
// 🔧 添加推仓阶梯状态保存
var addPosition1Status = ((ComboBoxItem)AddPosition1StatusComboBox.SelectedItem)?.Tag?.ToString() ?? "-";
var addPosition2Status = ((ComboBoxItem)AddPosition2StatusComboBox.SelectedItem)?.Tag?.ToString() ?? "-";
var addPosition3Status = ((ComboBoxItem)AddPosition3StatusComboBox.SelectedItem)?.Tag?.ToString() ?? "-";
var addPosition4Status = ((ComboBoxItem)AddPosition4StatusComboBox.SelectedItem)?.Tag?.ToString() ?? "-";

_logger.LogCritical($"🔥 推仓阶梯状态: T1={addPosition1Status}, T2={addPosition2Status}, T3={addPosition3Status}, T4={addPosition4Status}");

// 更新推仓阶梯状态到状态服务
try
{
    // 推仓阶梯1
    if (addPosition1Status == "√")
    {
        stateService.UpdateExecutionStatus(contractKey, "AddPosition", 1, true, 0, "手动设置为executed");
    }
    else if (addPosition1Status == "-")
    {
        stateService.UpdateExecutionStatus(contractKey, "AddPosition", 1, false, 0, "手动重置为waiting");
    }

    // 推仓阶梯2
    if (addPosition2Status == "√")
    {
        stateService.UpdateExecutionStatus(contractKey, "AddPosition", 2, true, 0, "手动设置为executed");
    }
    else if (addPosition2Status == "-")
    {
        stateService.UpdateExecutionStatus(contractKey, "AddPosition", 2, false, 0, "手动重置为waiting");
    }

    // 推仓阶梯3
    if (addPosition3Status == "√")
    {
        stateService.UpdateExecutionStatus(contractKey, "AddPosition", 3, true, 0, "手动设置为executed");
    }
    else if (addPosition3Status == "-")
    {
        stateService.UpdateExecutionStatus(contractKey, "AddPosition", 3, false, 0, "手动重置为waiting");
    }

    // 推仓阶梯4
    if (addPosition4Status == "√")
    {
        stateService.UpdateExecutionStatus(contractKey, "AddPosition", 4, true, 0, "手动设置为executed");
    }
    else if (addPosition4Status == "-")
    {
        stateService.UpdateExecutionStatus(contractKey, "AddPosition", 4, false, 0, "手动重置为waiting");
    }
}
catch (Exception ex)
{
    _logger.LogCritical($"🔥 推仓阶梯状态更新失败: {ex.Message}");
}
```

```csharp
// 🔧 从统一状态文件读取推仓阶梯状态
if (state.AddPositionConfig?.Tiers != null)
{
    var tier1 = state.AddPositionConfig.Tiers.FirstOrDefault(t => t.TierIndex == 1);
    var tier2 = state.AddPositionConfig.Tiers.FirstOrDefault(t => t.TierIndex == 2);
    var tier3 = state.AddPositionConfig.Tiers.FirstOrDefault(t => t.TierIndex == 3);
    var tier4 = state.AddPositionConfig.Tiers.FirstOrDefault(t => t.TierIndex == 4);

    config.AddPosition1Status = (tier1?.ExecutionState == ExecutionState.Executed) ? "√" : "-";
    config.AddPosition2Status = (tier2?.ExecutionState == ExecutionState.Executed) ? "√" : "-";
    config.AddPosition3Status = (tier3?.ExecutionState == ExecutionState.Executed) ? "√" : "-";
    config.AddPosition4Status = (tier4?.ExecutionState == ExecutionState.Executed) ? "√" : "-";
}
```

## 📝 注意事项

- 确保推仓阶梯的ExecutionState使用我们扩展的枚举（0=NotTriggered, 2=Executed）
- 移除"执行中"状态，只保留"已执行"和"未触发"
- 保持与保本状态相同的符号系统：√ 和 -
- 确保日志记录完整，便于调试
